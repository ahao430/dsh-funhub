05安装

已发布到 npm：在 DSH「插件」面板搜索 dsh-funhub 一键安装；或手动加进 desktop profile。

# 方式一：插件市场搜索 dsh-funhub，或手动：
cd ~/.dsh/profiles/desktop && pnpm add dsh-funhub
# package.json 的 dsh.profile.bundles 数组加 "dsh-funhub"

# 方式二（开发者）：git clone 后 link 本地路径
# 详见 README「安装」

# 重启 DeepSeek Harness，侧栏出现 FunHub

装好后到各频道的「设置 → 源管理」导入你自己的内容源即可使用。

06数据与隐私

FunHub 不内置任何内容源；你的源配置永远只在你本机。

所有源的配置（书源 / 漫画源 / 音源 / Emby 账密 / 图片 Key / RSS 订阅）都存在 $DSH_HOME/funhub/state.json（通常 ~/.dsh/funhub/），不在本仓库、不进 git。仓库的 .gitignore 对 state.json、*.local.json/js、.env* 做了防御性排除。Emby 的 API Key 只留在宿主侧，浏览器端拿不到。
项目位置进 git？

AI 生成素材（背景 / 贴纸）本仓库 assets/*.webp✅
